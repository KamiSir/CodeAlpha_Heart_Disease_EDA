# CodeAlpha_Heart_Disease_EDA

## 📊 Data Analytics Internship — CodeAlpha (Task 2 & 3)

This project performs Exploratory Data Analysis (EDA) and Data Visualization on the 
UCI Heart Disease dataset (920 patient records) to uncover patterns related to heart 
disease risk factors.

### 🎯 Objective
To explore relationships between clinical features (age, cholesterol, chest pain type, 
max heart rate, etc.) and the presence of heart disease.

### 🛠 Tools Used
- Python
- Pandas
- NumPy
- Matplotlib
- Seaborn
- Jupyter Notebook

### 🔍 Key Findings
- Patients with heart disease tend to be slightly older on average (56 vs. 51 years).
- Certain chest pain types are strongly associated with heart disease presence.
- Patients with heart disease show a noticeably lower average maximum heart rate 
  (128 vs. 149 bpm).
- Several columns contained invalid placeholder values (cholesterol/blood pressure 
  recorded as 0), which were identified and cleaned before analysis.

### 📁 Files
- `CodeAlpha_Heart_Disease_EDA.ipynb` — full notebook with code, charts, and analysis
- `heart_disease_uci.csv` — dataset used (UCI Heart Disease dataset)
